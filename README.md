# RFM Customer Segmentation Analysis

## Project Overview
This project focuses on customer segmentation using RFM (Recency, Frequency, Monetary) analysis to understand customer purchasing behavior and identify valuable customer groups.

## Objectives
- Analyze customer purchasing patterns.
- Calculate Recency, Frequency and Monetary values.
- Assign RFM scores to customers.
- Segment customers based on purchasing behavior.
- Identify high-value and at-risk customers.
- Develop marketing recommendations for different customer segments.

## Tools & Technologies
- SQL Server – Data analysis and RFM calculations.
- Microsoft Power BI – Interactive dashboard and visualization.
- CSV / Excel – Data preparation.

## Key Analysis
- Recency Analysis
- Frequency Analysis
- Monetary Analysis
- RFM Scoring
- Customer Segmentation
- Customer Cluster Analysis
- Marketing Recommendations

## Dashboard
The Power BI dashboard presents customer segmentation, RFM metrics and actionable business insights.

## Conclusion
RFM analysis helps businesses understand customer value, improve customer retention and develop targeted marketing strategies.
